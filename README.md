# Kevin's Python Projects

A collection of foundational Python scripts demonstrating core programming logic, user input handling, and mathematical functions.

## Project Directory

*   **bill's_calculator.py:** Processes numerical inputs to calculate total bills with automated splits.
*   **coffee_calculator.py:** Tracks individual user consumption patterns and tallies corresponding itemized costs.
*   **goal_tracker.py:** Formats and logs incremental milestone achievements against defined user parameters.
*   **guess_the_number.py:** Utilizes conditional logic loops to create an interactive terminal-based game.

## Key Skills Demonstrated

*   Algorithmic problem-solving
*   Data entry parsing and sanitization
*   Basic syntax structure control flows (`if/else` statements, loops)
